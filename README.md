# Project Name

Smart tech solutions web site.
## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (which includes npm)

### Installation and Usage

```bash
# 1. Clone the repository
git clone https://github.com/Smart-Tech-Solution92/smart-tech-website.git

# 2. Go into the project folder
cd smart-tech-website

# 3. Install dependencies
npm install

# 4. Run the project
npm start
```

That's it. No extra setup or configuration needed.
